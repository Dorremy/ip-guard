# IpGuard

Маленькая программа для трея Windows, которая следит за вашим внешним IP-адресом и сразу сообщает, если он изменился.

Нужна тем, кто работает через VPN и не хочет, чтобы сервисы видели «прыгающий» адрес. Многие сервисы подозрительно относятся к частой смене IP и могут заблокировать аккаунт. IpGuard показывает, что VPN подключился, что адрес прежний, и громко предупреждает, если что-то пошло не так.

## Что она делает

- Определяет внешний IP, страну и провайдера (через 2ip.io, запасной сервис — ipwho.is).
- Сравнивает адрес с **эталонным IP**, который вы задаёте сами. Эталон хранится отдельно для каждой страны, так что Германия и США не мешают друг другу.
- Проверяет адрес при запуске, после выхода компьютера из сна, при смене сети и каждые 15 секунд.
- Хранит историю проверок.
- Показывает цветную иконку в трее, уведомление Windows и проигрывает звук. Для каждого статуса свой звук, на выбор пять вариантов.

## Как понять, что происходит

| Иконка | Что значит |
|---|---|
| Зелёная | Всё в порядке: IP совпадает с эталонным для этой страны |
| Красная | **IP отличается от эталонного**. Это то, чего стоит опасаться |
| Оранжевая | VPN отключился, либо для этой страны ещё не задан эталон |
| Синяя | VPN не подключён, вы в домашней стране |
| Серая | Нет связи, адрес определить не удалось |

Примеры уведомлений:

- «Эталон не задан: United States (US), 203.0.113.10». Так бывает при первом подключении к стране. Если это нужный вам адрес, выберите в меню «Принять текущий IP как эталон».
- «Готов к работе: … IP совпадает с эталонным». Адрес тот, что вы задали.
- «IP отличается от эталонного! Сейчас: … 203.0.113.99. Эталонный IP: 203.0.113.10». Адрес не тот, что вы задали.
- «VPN отключился». Адрес стал домашним.

Если компьютер ушёл в сон или перезагрузился, после пробуждения программа сама перепроверит адрес. Если у VPN-клиента упало ядро и трафик пошёл напрямую, адрес снова станет домашним, и вы получите уведомление.

## Установка

1. Скачайте `IpGuard.exe` со страницы [Releases](../../releases).
2. Запустите. Программа появится в трее, установка не нужна.
3. Включите в меню трея пункт «Запускать вместе с Windows», если хотите, чтобы она стартовала сама.

Требования: Windows 10 или 11, 64-бит. Устанавливать .NET отдельно не нужно.

## Меню в трее

Правый клик по иконке:

- текущий IP, страна и провайдер;
- эталонный IP для текущей страны или пометка, что он не задан;
- **Проверить сейчас**;
- **Принять текущий IP как эталон**: запомнить текущий адрес как правильный для этой страны. Так же меняется старый эталон;
- **Считать текущую страну домашней**: по умолчанию домашней считается Россия (RU). Подключитесь без VPN и выберите этот пункт, если живёте в другой стране;
- **История**: все проверки с датой, адресом, страной и провайдером; двойной клик по иконке открывает её же;
- **Звуки**: включить или выключить, а для каждого статуса выбрать один из пяти вариантов. При выборе звук сразу проигрывается;
- **Запускать вместе с Windows**;
- **Открыть папку с данными**;
- номер версии;
- **Выход**.

## Где хранятся данные

В папке `%AppData%\IpGuard`:

- `state.json`: эталонные адреса и история (последние 1000 записей);
- `settings.json`: домашняя страна, интервал проверки в секундах (по умолчанию 15, минимум 15) и настройки звуков.

Файлы можно править руками, программа перечитывает их при запуске.

## Приватность

Программа обращается только к сервисам определения IP (2ip.io и ipwho.is) и отправляет им обычный запрос, как это делает браузер. Ваши данные хранятся только на вашем компьютере.

## Сборка из исходников

Нужен [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0).

```bash
dotnet publish src/IpGuard -c Release -r win-x64 --self-contained -p:PublishSingleFile=true -o dist
```
