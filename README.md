# IpGuard

Маленькая программа для трея Windows, которая следит за вашим внешним IP-адресом и сразу сообщает, если он изменился.

Нужна тем, кто работает через VPN и не хочет, чтобы сервисы видели «прыгающий» адрес. Многие сервисы подозрительно относятся к частой смене IP и могут заблокировать аккаунт. IpGuard показывает, что VPN подключился, что адрес прежний, и громко предупреждает, если что-то пошло не так.

## Что она делает

- Определяет внешний IP, страну и провайдера. Сервисы опрашиваются по очереди (2ip.io, ipwho.is, ipinfo.io, ifconfig.co), а тот, что ответил «лимит исчерпан», пропускается на 30 минут.
- Сравнивает адрес с **эталонными IP**, которые вы задаёте сами. Эталоны хранятся отдельно для каждой страны, так что Германия и США не мешают друг другу. Для одной страны можно сохранить несколько адресов с подписями, например основной и резервный сервер: IP считается верным, если совпал с любым из них.
- Ищет утечки мимо VPN. Если VPN работает в режиме системного прокси, программа сравнивает адрес браузера с адресом, с которого выходят программы без прокси (например, консольные утилиты). Отдельно проверяет IPv6: он часто идёт напрямую через домашнего провайдера.
- Проверяет адрес при запуске, после выхода компьютера из сна, при смене сети и каждые 15 секунд.
- Следит за временем без связи. Короткие моргания сети проходят тихо, а если связи нет дольше 30 секунд (задержку можно изменить в меню), приходит тревога «Нет связи больше 30 с» со временем начала. Когда связь возвращается, в уведомлении сказано, сколько её не было, а в истории появляется отдельная запись.
- Хранит историю проверок и ведёт журнал работы.
- При опасных событиях (IP отличается от эталонного, утечка мимо VPN) показывает окно тревоги поверх всех окон и повторяет звук, пока вы его не закроете. Окно не забирает фокус, так что набор текста не прервётся. Перед тревогой «IP отличается» адрес перепроверяется через другой сервис, чтобы единичная ошибка сервиса не пугала зря.
- Показывает цветную иконку в трее, уведомление Windows и проигрывает звук. Для каждого статуса свой звук, на выбор пять вариантов.

## Как понять, что происходит

| Иконка | Что значит |
|---|---|
| Зелёная | Всё в порядке: IP совпадает с эталонным для этой страны |
| Красная | **IP отличается от эталонного** или **найдена утечка мимо VPN**. Это то, чего стоит опасаться |
| Оранжевая | VPN отключился, либо для этой страны ещё не задан эталон |
| Синяя | VPN не подключён, вы в домашней стране |
| Серая | Нет связи, адрес определить не удалось. Если так дольше 30 секунд, приходит уведомление |

Примеры уведомлений:

- «Эталон не задан: United States (US), 203.0.113.10». Так бывает при первом подключении к стране. Если это нужный вам адрес, выберите в меню «Принять текущий IP как эталон».
- «Готов к работе: … IP совпадает с эталонным (основной)». Адрес тот, что вы задали, в скобках его подпись. Если вы переключились на другой сохранённый адрес (например, на резервный сервер), придёт такое же уведомление.
- «IP отличается от эталонного! Сейчас: … 203.0.113.99. Эталонный IP: 203.0.113.10». Адрес не тот, что вы задали. Если эталонов несколько, перечислены все: «Эталонные IP: 203.0.113.10 (основной), 203.0.113.20 (резерв)».
- «VPN отключился». Адрес стал домашним.
- «Утечка мимо VPN! Программы без прокси выходят напрямую, мимо VPN: Russia (RU), 192.0.2.5. Браузер: 203.0.113.10». VPN включён в режиме системного прокси, и часть программ ходит мимо него. Включите в VPN-клиенте режим TUN (VPN-режим) или задайте программам прокси.
- «Прокси не отвечает!». VPN-клиент работает в режиме системного прокси, но прокси перестал отвечать (например, упало ядро), а напрямую интернет есть, то есть программы без прокси выходят с домашнего адреса. Тревога приходит сразу, без задержки.
- «Утечка мимо VPN! IPv6 идёт мимо VPN: …». Отключите IPv6 в настройках сетевого адаптера или включите его поддержку в VPN-клиенте.

Если компьютер ушёл в сон или перезагрузился, после пробуждения программа сама перепроверит адрес. Если у VPN-клиента упало ядро и трафик пошёл напрямую, адрес снова станет домашним, и вы получите уведомление.

## Установка

1. Скачайте `IpGuard.exe` со страницы [Releases](../../releases).
2. Запустите. Программа появится в трее, установка не нужна.
3. Откройте «Настройки...» и отметьте «Запускать вместе с Windows», если хотите, чтобы она стартовала сама.

Требования: Windows 10 или 11, 64-бит. Устанавливать .NET отдельно не нужно.

**Лёгкая сборка.** Начиная с версии 0.5.2 рядом с `IpGuard.exe` (около 70 МБ, работает сразу) в релизе лежит `IpGuard-light.exe` (около 3 МБ). Он делает то же самое, но требует установленного [.NET 8 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/8.0). Если его нет, Windows сама предложит скачать. Выбирайте лёгкую сборку, если среда .NET у вас уже стоит или важен размер файла.

## Меню в трее

Правый клик по иконке:

- текущий IP, страна и провайдер;
- если включён системный прокси: адрес, с которого выходят программы без прокси;
- адрес IPv6 (или «нет») для текущей страны;
- эталонный IP для текущей страны или пометка, что он не задан;
- **Проверить сейчас**;
- **Принять текущий IP как эталон**: добавить текущий адрес в эталоны этой страны. Старые эталоны остаются, убрать их можно в окне «Эталоны»;
- **Эталоны...**: список всех эталонов. Здесь можно добавить текущий IP (с подписью), изменить подпись и удалить эталон;
- **Считать текущую страну домашней**: по умолчанию домашней считается Россия (RU). Подключитесь без VPN и выберите этот пункт, если живёте в другой стране;
- **История**: все проверки с датой, адресом, страной, провайдером и примечанием (при утечке там написано, что именно обнаружено); двойной клик по иконке открывает её же. В окне можно отфильтровать записи по стране и статусу, найти нужное по тексту (IP, провайдер, примечание), сохранить показанное в файл CSV (откроется в Excel) и очистить историю. Открытое окно обновляется само, когда появляются новые записи;
- **Не беспокоить**: на 15, 30 или 60 минут отключает звуки и всплывающие уведомления, иконка при этом продолжает менять цвет. Окно тревоги при расхождении IP и утечке всё равно появится, но без звука: такие события пропускать нельзя. Режим не сохраняется при перезапуске программы;
- **Настройки...**: окно со всеми параметрами (описано ниже);
- **Открыть папку с данными**;
- **Открыть журнал**: когда что проверялось, что менялось и какие были тревоги;
- **Резервная копия настроек**: «Сохранить в файл...» записывает настройки и эталоны в файл, «Загрузить из файла...» читает их обратно. Перед загрузкой программа показывает, что в файле, включает ли он защиту и какие значения пришлось исправить. Файл проверяется: значения приводятся к допустимым, системные программы в список защиты не попадают. Это удобно при переустановке или переносе на другой компьютер. История проверок и журнал в копию не входят.
- **Проверить обновления**: сразу спросить у GitHub, вышла ли новая версия. Если вышла, над этим пунктом появляется «Доступна версия …», и клик откроет страницу загрузки;
- номер версии;
- **Выход**.

## Настройки

Пункт «Настройки...» открывает окно. Изменения применяются по кнопке «Сохранить», «Отмена» ничего не меняет.

- **Домашняя страна**: выбирается из списка. Это страна, где вы бываете без VPN.
- **Интервал проверки**: от 15 секунд до часа.
- **Запускать вместе с Windows**.
- **Проверки утечек**: отдельно включается проверка прямого маршрута (без прокси) и проверка IPv6.
- **Сообщать о потере связи**: сразу, через 15 секунд, через 30 секунд (по умолчанию) или через минуту.
- **Окно тревоги**: если выключить, тревоги приходят обычным уведомлением Windows.
- **Звуки**: включить или выключить, задать громкость и для каждого статуса выбрать один из пяти звуков («Два колокольчика вверх», «Сирена», «Маримба с эхом» и другие). Кнопка «▶» проигрывает выбранный звук с текущей громкостью, не дожидаясь сохранения.
- **Для скриптов**: отдавать статус по локальному адресу (см. раздел «Для скриптов» ниже), порт можно изменить.
- **Защита**: закрывать выбранные программы при опасной ситуации (описано в разделе «Защита» ниже). По умолчанию выключено.
- **Обновления**: раз в сутки программа спрашивает у GitHub, не вышла ли новая версия. Сама она ничего не скачивает и не устанавливает, а только сообщает об этом и открывает страницу релиза. Проверку можно выключить.

## Защита

Если включить этот пункт в настройках, при опасной ситуации программа попросит закрыться выбранные вами программы, например терминал, где вы работаете. По умолчанию защита выключена, при включении программа предупреждает о последствиях.

- **Когда срабатывает.** Всегда можно включить реакцию на красную тревогу: IP отличается от эталонного, утечка мимо VPN, прокси не отвечает. Отдельно можно включить реакцию на потерю связи и задать, сколько секунд связи нет до срабатывания (например, 30).
- **Как закрывает.** Программам посылается обычная просьба закрыть окно, как при щелчке по крестику. Если в программе есть несохранённая работа, она сама спросит про сохранение. Принудительно (с потерей данных) программа ничего не завершает.
- **Время на отмену.** Перед закрытием появляется окно с обратным отсчётом (по умолчанию 10 секунд) и кнопками «Закрыть сейчас» и «Не закрывать». Так ложную тревогу можно отменить. Если поставить 0, закрытие произойдёт сразу.
- **Один раз за инцидент.** Пока ситуация не вернулась в норму, программы не будут закрываться повторно.
- **Какие программы.** В настройках кнопка «Добавить запущенную...» показывает программы с открытыми окнами, а «Добавить по имени...» принимает имя процесса, например `WindowsTerminal` или `chrome`. Системные программы (проводник, службы Windows) и сама IpGuard добавить нельзя.

## Для скриптов

Программа всегда записывает текущее состояние в файл `%AppData%\IpGuard\status.json` и обновляет его после каждой проверки. Дополнительно (если включить в настройках пункт «Отдавать статус скриптам на этом компьютере») она отвечает по локальному адресу, который доступен только с этого же компьютера.

| Адрес | Ответ |
|---|---|
| `http://127.0.0.1:47831/status` | JSON с подробным состоянием |
| `http://127.0.0.1:47831/ok` | код 200 и слово `ok`, если IP совпадает с эталонным; иначе код 503 и название состояния |

Порт по умолчанию 47831, его можно изменить в настройках. Сервер слушает только `127.0.0.1`, принимает только запросы на чтение и отклоняет запросы с чужим именем хоста.

Поля JSON: `ok` (можно ли работать), `state` (`ok`, `no_reference`, `changed`, `leak`, `vpn_off`, `home`, `offline`, а в файле ещё `stopped`, когда программа закрыта), `title`, `message`, `ip`, `countryCode`, `country`, `provider`, `references` (эталоны текущей страны), `leak`, `updatedUtc`, `version`. В ответе по адресу есть ещё `ageSeconds`: сколько секунд назад был обновлён статус.

Если читаете файл, проверяйте время в `updatedUtc`: если программа аварийно завершилась, в файле останется последнее значение. Разумно считать статус устаревшим, когда ему больше двух минут.

Пример для PowerShell: не запускать программу, если IP не тот.

```powershell
try {
    $status = Invoke-RestMethod http://127.0.0.1:47831/status
} catch {
    Write-Error "IpGuard не отвечает"
    exit 1
}
if (-not $status.ok) {
    Write-Error "Запуск отменён: $($status.title). $($status.message)"
    exit 1
}
& "C:\Path\To\program.exe"
```

Пример для bash (curl вернёт ошибку при коде 503):

```bash
curl -fs http://127.0.0.1:47831/ok > /dev/null || { echo "IP не совпадает с эталоном" >&2; exit 1; }
./my-program
```

Пример для чтения файла в PowerShell, с проверкой свежести:

```powershell
$path = Join-Path $env:APPDATA 'IpGuard\status.json'
$status = Get-Content $path -Raw -Encoding UTF8 | ConvertFrom-Json
$age = (Get-Date).ToUniversalTime() - [datetime]$status.updatedUtc
if (-not $status.ok -or $age.TotalMinutes -gt 2) { exit 1 }
```

## Где хранятся данные

В папке `%AppData%\IpGuard`:

- `state.json`: эталонные адреса с подписями и история (последние 1000 записей). Файл от прежних версий, где у страны был один адрес, при первом запуске переносится в новый формат автоматически;
- `log.txt`: журнал работы. В него попадают запуск, изменения адреса или статуса, тревоги и проверки после сна, смены сети и по кнопке. При размере больше 1 МБ старый журнал переименовывается в `log.1.txt`;
- `status.json`: текущее состояние для скриптов (см. раздел «Для скриптов»);
- `settings.json`: домашняя страна, интервал проверки в секундах (по умолчанию 15, минимум 15) и настройки звуков и проверок утечек.

Папку для данных можно заменить: если задать переменную окружения `IPGUARD_DATA_DIR` с полным путём, программа будет хранить все файлы там. Это удобно для переносной копии и для проверок, чтобы не трогать основные данные. У каждой такой папки своя защита от двойного запуска, поэтому такую копию можно запустить рядом с обычной.

Файлы можно править руками, программа перечитывает их при запуске.

## Приватность

Программа обращается к сервисам определения IP (2ip.io, ipwho.is, ipinfo.io, ifconfig.co и api6.ipify.org) и раз в сутки к `api.github.com` за номером последней версии (это можно выключить в настройках) и отправляет им обычный запрос, как это делает браузер. Ваши данные хранятся только на вашем компьютере.

## Сборка из исходников

Нужен [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0).

```bash
dotnet publish src/IpGuard -c Release -r win-x64 --self-contained -p:PublishSingleFile=true -o dist
```

Лёгкая сборка (нужен .NET 8 Desktop Runtime):

```bash
dotnet publish src/IpGuard -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true -o dist-light
```
